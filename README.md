# jhontrauco.dev

Sitio personal de Jhon Trauco, estudiante de Ingeniería de Sistemas
(Universidad Nacional Toribio Rodríguez de Mendoza, Amazonas, Perú).

Cumple dos funciones: captar clientes locales que todavía no tienen
presencia web (hospedajes, restaurantes, comercios de la ruta turística
a Kuélap y Gocta), y servir de portafolio.

**Sitio publicado:** https://jhontrauco.github.io/

## Stack

HTML, CSS y JavaScript puros — sin frameworks, sin paso de compilación,
sin dependencias externas más allá de Google Fonts y la API de
[Web3Forms](https://web3forms.com) para el formulario de contacto.
Los archivos del repositorio son exactamente los que sirve el navegador.

## Estructura

```
jhontrauco.github.io/
├── index.html
├── css/estilos.css
├── js/main.js
└── img/preview.png
```

## Funciona sin JavaScript

Salvo el envío del formulario, el cambio de tema y el cierre del menú
móvil, todo el sitio es HTML/CSS puro y funciona con JavaScript
desactivado.

## Despliegue

GitHub Pages desde la rama `main`, carpeta raíz. Cualquier commit a
`main` publica automáticamente.
